# NestPath

A companion app for new parents.

This repo is being built in phases. **Phase 0** (`backend/reference-data/`)
produced sourced CDC vaccine-schedule and WHO growth-percentile reference
data. **Phase 1** (this phase) is scaffolding only: a FastAPI backend, a
Next.js frontend, and a proof that they can talk to each other. No
business logic, auth, or real UI yet — that starts in Phase 2.

## Project layout

```
backend/             FastAPI app + SQLAlchemy models + Alembic migrations
  app/
    main.py           FastAPI app, /health endpoint
    database.py        SQLAlchemy engine/session (reads DATABASE_URL)
    models.py           Family, Child, Caregiver, ScheduleItem
  alembic/              Migration environment and versions
  reference-data/        Phase 0 CDC/WHO reference data (see its own README)
  requirements.txt
  .env.example

frontend/            Next.js app
  app/page.tsx         Calls backend /health and displays the result
```

## Prerequisites

- Python 3.12+
- Node.js 20+
- A running PostgreSQL instance (local install, or `docker run` — see below)

## Backend setup

```bash
cd backend
python -m venv .venv
```

Activate the virtual environment:

```bash
# macOS/Linux
source .venv/bin/activate
# Windows (PowerShell)
.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Set up your environment file:

```bash
cp .env.example .env
```

Edit `.env` and set `DATABASE_URL` to point at a real Postgres database,
e.g. for a quick local instance via Docker:

```bash
docker run -d --name nestpath-db \
  -e POSTGRES_USER=nestpath -e POSTGRES_PASSWORD=changeme -e POSTGRES_DB=nestpath \
  -p 5432:5432 postgres:16-alpine
```

Run migrations:

```bash
alembic upgrade head
```

Start the API server:

```bash
uvicorn app.main:app --reload
```

The backend runs at `http://localhost:8000`. Confirm it's up:

```bash
curl http://localhost:8000/health
# {"status": "ok"}
```

## Frontend setup

In a separate terminal:

```bash
cd frontend
npm install
npm run dev
```

The frontend runs at `http://localhost:3000` and shows whether it could
reach the backend's `/health` endpoint. By default it calls
`http://localhost:8000`; override with a `NEXT_PUBLIC_API_URL` environment
variable if your backend runs elsewhere.

## Running both together

Start the backend (`uvicorn app.main:app --reload` in `backend/`) and the
frontend (`npm run dev` in `frontend/`) in two terminals, then open
`http://localhost:3000` — it should show `{"status": "ok"}` if both sides
are wired up correctly.

## Creating new migrations

After changing a model in `backend/app/models.py`:

```bash
cd backend
alembic revision --autogenerate -m "describe the change"
alembic upgrade head
```

Always review autogenerated migrations before applying them — Alembic
does not reliably detect every kind of change (e.g. it won't emit a
`DROP TYPE` for a removed Postgres enum on downgrade; see the initial
migration for an example fix).
